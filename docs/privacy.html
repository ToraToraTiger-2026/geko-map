プライバシーポリシー

運営者（以下「運営者」）は、下戸マップ（以下「本サービス」）における利用者の情報を、次のとおり取り扱います。

1. 取得する情報と利用目的

情報内容・取得の方法利用目的
仮ID 投稿や通報などをするときに、端末ごとに自動で発行される目に見えない識別子です。お名前やメールアドレスとは結びつきません。端末のブラウザ内に保存されます。 投稿回数の制限、いたずら・不正投稿の防止、重複した評価の防止
投稿内容 お店の名前、住所、地図上の位置、特徴の選択、GoogleマップのID（任意）、通報の理由と補足 本サービス上での表示（承認後）、運営の確認
メールアドレス 削除依頼フォームで、任意で入力された場合のみ 削除依頼への返信。管理者以外には表示されません。
接続情報 IPアドレス、ブラウザの種類など。利用する外部サービス（下記）のサーバーに記録されます。 サービスの提供、不正利用の防止

投稿者名は取得せず、表示もしません。

2. 保管期間

  • 削除依頼のメールアドレス：対応が完了してから6か月後に削除します。
  • 仮ID：作成から30日が過ぎ、未対応の投稿がないものは、定期的に削除します。承認された投稿は、仮IDが削除されても残ります。
  • 承認された投稿：削除依頼などで削除するまで保管します。

3. 第三者への提供

法令に基づく場合を除き、取得した情報を本人の同意なく第三者に提供しません。

4. 利用する外部サービス

本サービスは、次の外部サービスを利用しています。利用者がページを開くと、これらのサービスに接続情報（IPアドレスなど）が送信されます。

  • Supabase（データベースと仮IDの管理。日本のリージョンを使用）
  • GitHub Pages（サイトの配信）
  • OpenStreetMap（地図画像の配信）
  • Cloudflare Turnstile（ロボットによる不正投稿の判定）
  • Google マップ（お店のリンク先。リンクを開いたときのみ接続されます）

5. ブラウザへの保存

本サービスは、仮IDを維持するために、ブラウザのローカルストレージ（端末内の保存領域）を使います。広告や行動追跡のための Cookie は使用していません。ブラウザの設定でデータを消すと、仮IDも消え、新しい仮IDになります。

6. 開示・訂正・削除のご請求

運営者が保有する情報の開示・訂正・削除をご希望の場合は、削除依頼フォームからご連絡ください。仮IDは個人を特定できない情報のため、投稿との照合ができない場合があります。

7. 改定

必要に応じて、このポリシーを改定します。改定後は、このページに掲載した時点で効力を生じます。
